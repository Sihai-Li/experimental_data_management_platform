# Project conventions

## Language

- All user-facing web content must be in English. This includes page titles, navigation, buttons, forms, placeholders, status labels, errors, notifications, accessibility labels, and browser-visible reports.
- Use English locale formatting for UI dates and times. Set the HTML language to English.
- Project documentation and communication with the project owner may be in Chinese.
- Preserve source scientific data and identifiers exactly; do not translate stored values.
- Apply this convention to future features and UI changes. The laboratory users are English-speaking.

## Data

- Never commit real recording data. Keep spatial_data_pre_training and all MAT files ignored.
- Do not modify original sample files for testing; use temporary copies.
